Module 01

Set Theory & Operations

Formal foundations, set representations, algebraic laws, and Inclusion-Exclusion principles.

S

The Concept of a Set

A well-defined collection of distinct objects called elements or members.

Roster: V = {a, e, i, o, u}

Builder: V = {x | x is a vowel}

Membership: 2 ∈ A, 5 ∉ A

P

Power Set & Subsets

The power set ℘(A) contains all possible subsets of A. Total quantity is strictly 2ⁿ.

If A = {1, 2}:

℘(A) = { ∅, {1}, {2}, {1,2} }

Cardinality: |℘(A)| = 2² = 4

Proper Subsets: 2ⁿ - 1 = 3

E

Equality vs Equivalence

Equal sets share exact elements. Equivalent sets share identical cardinality.

Equal (A = B): {1,2,3} = {3,2,1}

Equivalent (A ~ B): |{1,2,3}| = |{x,y,z}| = 3

Empty Set: |∅| = 0

Module 02

Relations & Functions

Domain and range analysis, mapping classification, and polynomial function evaluation.

Core Concepts: Relation vs Function

A relation is any set of ordered pairs (x, y). The domain is the set of all input values (x-coordinates), while the range is the set of output values (y-coordinates).

// Relation Sample:

R = {(-2, 1), (-2, 3), (0, -3), (1, 4), (3, 1)}

Domain = {-2, 0, 1, 3}

Range = {-3, 1, 3, 4}

A function is a special relation where every input x is mapped to EXACTLY ONE output y. It must pass the Vertical Line Test on a Cartesian graph.

Activity A Solved Key: Function Identification

1. J = {(5,10), (-2,10), (15,10), (-4,10)}

Result: Function (Many-to-one; all x values are unique).

2. A = {(11,-2), (3,2), (-11,2), (-3,2)}

Result: Function (All x inputs are unique).

3. K = {(1,2), (1,3), (2,1), (2,4)}

Result: Not a Function (x=1 pairs with 2 & 3).

4. L = {(x,y) | y = x²}

Result: Function (Parabola passes vertical line test).

5. B = {(x,y) | x² + y² = 9}

Result: Not a Function (Circle radius 3; x=0 yields y=±3).

1. g(x) = x³ + 2x² - x - 1

• g(-1) = (-1)³ + 2(-1)² - (-1) - 1 = -1 + 2 + 1 - 1 = 1

• g(0) = 0³ + 2(0)² - 0 - 1 = -1

• g(3) = 3³ + 2(3)² - 3 - 1 = 27 + 18 - 4 = 41

• f(-2) = (-2)³ - 4(-2)² + 3(-2) - 2 = -8 - 16 - 6 - 2 = -32

• f(3) = (3)³ - 4(3)² + 3(3) - 2 = 27 - 36 + 9 - 2 = -2

3. g(x) = 2x² - x - 1 (Exit Pass 2)

• g(-2) = 2(-2)² - (-2) - 1 = 8 + 2 - 1 = 9

• g(2) = 2(2)² - (2) - 1 = 8 - 2 - 1 = 5

Module 03

Induction, Deduction & Logic

Reasoning patterns, truth table evaluations, and variations of conditional propositions.

I

Inductive Reasoning

Derives general conclusions/conjectures from specific observations or trends. Conclusions are probable, but not guaranteed to be true.

Pattern: 2, 4, 8, 16, ...

Conjecture: Next term will be 32.

Observation: Sun rises in East every day so far → Will probably rise in East tomorrow.

D

Deductive Reasoning

Establishes specific conclusions derived logically from accepted general premises or definitions. Conclusions are guaranteed true.

Premise 1: Numbers ending in 0 or 5 are divisible by 5.

Premise 2: 35 ends in 5.

Conclusion: 35 is guaranteed divisible by 5.

Variations of Conditional Propositions (p → q)

A conditional statement and its contrapositive are logically equivalent (p → q ≡ ~q → ~p).

Direct Conditional If p, then q

"If it rained, then the grounds are wet."

Converse If q, then p

"If the grounds are wet, then it rained."

Inverse If ~p, then ~q

"If it did not rain, then grounds are not wet."

Contrapositive If ~q, then ~p

"If grounds are not wet, then it did not rain."

Logical Operator Truth Distribution

Quick Self-Test Practice Key

Q1: If |A| = 5, how many proper subsets exist?

Answer: 2⁵ - 1 = 32 - 1 = 31 proper subsets.

Q2: Domain/Range of R = {(1,5), (2,6), (3,7), (4,5)}?

Domain = {1, 2, 3, 4}, Range = {5, 6, 7}. Function!

Q3: Contrapositive of "If x is a multiple of 4, then x is even"?

Answer: "If x is not an even number, then x is not a multiple of 4."
